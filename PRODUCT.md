# Product

## Register

brand

## Platform

web

## Users

Filipino households and families tracking shared day-to-day spending. The primary user is the person who initiated the budget — a salaried worker, freelancer, or student managing household finances for 2–4 people. They've tried apps before and abandoned them by week two. They're not looking for a financial advisor; they're looking for something fast enough that logging a transaction doesn't feel like a chore.

## Product Purpose

LedgeIt lets households log expenses and income in under 5 seconds using plain language — no forms, no category dropdowns, no friction. Success looks like a household that still uses the app a month after signing up, because the barrier to logging was low enough that the habit stuck.

## Positioning

The fastest way a household has ever tracked spending — type it the way you'd say it, and it's done.

## Brand Personality

Smart, minimal, frictionless. The voice is confident without being loud — like a product that knows exactly what it does and doesn't need to over-explain. Tone is direct, slightly warm, never corporate. The interface earns trust through speed and clarity, not reassurance copy.

## Anti-references

- Generic fintech blue / gold: navy palettes, gold accents, anything that reads as "bank app" or "investment platform". LedgeIt is a household tool, not a wealth product.
- Neon / crypto aesthetic: dark-mode glows, electric accents, speculative energy. LedgeIt should feel permanent and calm, not volatile.
- Overwhelming dashboards: Mint-style information overload where the first screen is a wall of charts. Every screen should have one clear purpose.

## Design Principles

1. **Frictionless above all**: every interaction should cost the user as little effort as possible. If it feels like work, redesign it.
2. **Speed is the feature**: the core promise is under-5-second logging. The UI must make that feel true — fast animations, no loading states where avoidable, instant feedback.
3. **Calm confidence**: the app handles money, which is stressful. The design should never amplify that stress. Green is deliberate — it signals growth and calm, not urgency.
4. **Households, not solo users**: shared context is native, not an afterthought. Copy, empty states, and flows assume multiple contributors.
5. **Show, don't reassure**: earn trust through the product experience, not through trust-badge copy or security jargon.

## Accessibility & Inclusion

No formal WCAG level set yet. Treat WCAG AA as the practical floor for all text contrast and interactive targets. Given the household audience, support reduced-motion preferences as a sensible default.
